## Release 2 — The Engineer's Console

- Forensic replay — preview-then-commit scrub mode. R2's forensic replay ships as a destructive rewind: clicking a timeline event loads to that tick and the post-rewind state is forfeit. A nicer UX is preview during drag (dashboard shows historical state without touching the live run), with an explicit "rewind here" commit button or a release-to-cancel. That design needs the host to maintain two parallel states (live and scrub-preview) and a query path that can serve historical state without disturbing the active run — a meaningful new architecture. Deferred until destructive scrub proves load-bearing enough to justify the lift; in the interim, Save-before-scrub gives the player a safe-out one click away. #r2-stretch #ui #host
- Phylogeny redesign — muller plot (Passes 1 and 2). Replace the per-lineage row stack with a population-banded clade flow: y-axis is share-of-population (always 100%, canvas-bounded), x-axis is tick, each clade is a coloured stream whose thickness is its live population at that tick, speciation is a tributary split, extinction pinches to zero. Default filter shows living clades + their direct ancestors (per the hide-don't-compress codified pattern); an "include extinct" toggle reveals the rest. Closes both the legibility complaint ("still a bit baffling") and the long-run row-scaling problem (no rows → no per-row pixel ceiling) in one stroke. Pass 0 shipped at commit `8656fc9` (extinctionTick on lineageTree). **Pass 1**: muller plot over the existing 240-sample `populationHistory` rolling window — UI-only, no protocol change. **Pass 2**: add a `phylogenyHistory` query that returns per-clade population time-series at a sim-side sample cadence (suggested every 100 ticks) for full-run fidelity — additive protocol change. Alternatives rejected during brainstorm: drift-envelope clade collapse (captures current state, not history), radial cladogram (same equal-weight problem as today's view), stroke-width modulation alone (keeps rows), virtualised scrolling (fixes ceiling, not legibility), pure significance-threshold decimation (silent information loss), time-binning (absorbed as horizontal-scaling fallback). Open guesses to validate before shipping Pass 1: default-show-living-only vs include-extinct; 100% stacked vs absolute population; DFS sibling stacking order; sample cadence; whether the toggle should default off; whether the existing PhylogenyView keeps as a "rows" alt view or gets retired. #r2-stretch #ui #protocol

## Release 3 — First Contact (MVP brief; not yet started)

This section is a kickoff brief, not yet a worklist. Every line below carries unresolved player-input decisions; **do not start implementation without re-running the design pass with the player.** Roughly thirty micro-decisions were flagged in the original brainstorm (now deleted); the items below capture the load-bearing shape only.

- R3 mechanic — The Others as episodic incursions. Single archetype ("Replicators") at R3; no firmware until R6. Spawn cadence around 50,000 ticks plus jitter. Encounter is a probe-vs-incursion roll between basal metabolism and death (one PRNG draw per encounter — determinism golden will need regenerating). Player perceives them via the substrate panel + a new dashboard surface; they are NOT probes and do NOT speciate. Design tension: keeping them "not firmware" preserves the R3 scope cut but means R6's promotion to a full firmware sim is a meaningful retroactive change. #r3 #sim #spec
- R3 mechanic — Deltans as a per-cell boolean flag. NOT entities, NOT firmware, NOT diplomacy AI. A single bit on a single cell that flips to "Deltan-present" at world-gen for a small set of cells (determinism rolls at newRun, gated by seed). Probes can occupy, gather, or replicate at a Deltan cell; each of those acts triggers a treaty-violation event of escalating severity (occupy = sticky lineage flag, gather = sticky-plus, replicate-on-cell = extinguishes the Deltans entirely on that cell). This is the cheapest implementation that produces narrative consequences and the smallest surface to walk back if R5+ wants Deltans to grow into anything richer. #r3 #sim
- R3 mechanic — three severities of treaty violation, sticky per lineage. Each violation kind sets a sticky flag on the offending lineage that persists across speciation (descendants inherit the taint). Surfaces in the lineage inspector and as a first-class rewindable event in the timeline. The "tainted-flag-lands-now-used-in-R4" coupling is flagged: R4 archetypes may key off taint, so locking the flag shape pre-R4 carries a small forward-compat risk. #r3 #sim #protocol
- R3 mechanic — crisis-mode pacing as a soft speed cap. Not a separate sim mode; a 4× ceiling on `setSpeed` that lifts silently when the crisis condition clears. Triggered by `firstContact` and `treatyViolation` events; cleared when no recent (last N ticks) crisis event is on the timeline. #r3 #sim #ui
- R3 player verb — one new decree trigger only. A `proximityToCell` trigger so the player can queue an avoidance-zone decree around Deltan cells (or any cell). NO emergency-patch verb, NO crisis-aware compute cost, NO contact-protocol authoring surface. Smallest possible new verb; bigger surfaces wait until R3 ships and proves the loop. #r3 #ui #spec
- R3 groundwork — fog-of-war as cheap R7 down-payment. R7's "long shadow" arc presumes probe-side discovery. Add a per-cell discovered/undiscovered flag in R3 (player-visible: undiscovered cells render dim on substrate panel; discovery happens on first probe entry) so first-contact events read coherently as "we just met the Others." Costs almost nothing; meaningful narrative scaffolding for R5–R7. #r3 #sim #ui
- R3 protocol additions (all additive). `IncursionSpawned` / `OtherEncounter` / `DeltanExtinction` / `FirstContact` / `TreatyViolation` / `EntityDiscovered` events; `othersState` query; `proximityToCell` trigger spec. FirstContact / TreatyViolation / DeltanExtinction / IncursionSpawned slot in as first-class rewindable per the two-strata timeline already on main; OtherEncounter and EntityDiscovered demoted to background. #r3 #protocol
- R3 acceptance gates (proposed draft, not approved). (1) An Others incursion has fired at least once in a 100k-tick seed=42 run. (2) A Deltan cell exists and a treaty-violation event fires when a probe gathers from it. (3) The lineage inspector shows the sticky taint flag set on the offending lineage and its descendants. (4) Crisis-mode pacing caps speed at 4× while a firstContact or treatyViolation event sits inside the last N ticks. (5) The `proximityToCell` decree trigger fires when a probe enters the configured radius. (6) Determinism golden regenerated and passing. (7) Headless CLI replays a recorded R3 run to byte-identical event log. (8) E2E test exercises the full first-contact + decree-response flow end-to-end. #r3 #spec
- R3 determinism caveat. The Deltan world-gen roll consumes a fresh PRNG draw at newRun, so every existing determinism golden (`test/determinism/golden/*.ndjson`) will need regenerating once R3 lands. Flag for the ship commit; not a blocker, just an audit-time gotcha. #r3 #sim #test
