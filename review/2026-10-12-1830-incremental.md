## Invariants

Carried forward from the full review, amended where noted. These held at `9eb84dd`:

- `sim/` imports only its own modules and type-only `protocol/types.js`. It uses no DOM, Node API, `Date`, `performance` or `Math.random`, and ESLint enforces the main cases (`eslint.config.js:31-91`).
- Probabilities are u64 thresholds, and simulation accounting is integer-only. PRNG draws depend only on documented conditions, and quarantine funding consumes none.
- `snapshot`/`restore` round-trip all 14 `SimState` fields. This includes PRNG state, quarantine insertion order, decree and patch order, and Map insertion order for probes and lineages.
- Diffusion conserves total resources exactly and never produces negative cells.
- Proto field numbers are not reused, and the 15 `SimEvent` kinds match the proto oneof. Protocol messages are plain data.
- Log entries are ordered by `(tick, seq)`. Rewind keeps entries at or before the target and resumes the sequence after them, and replay skips save, deleteSave, switchRun and deleteRun.
- Switch, rewind and load prepare state in an isolated host. On failure the live state, writer, marker and log stay unchanged and the run stays paused. Concurrent commands are rejected without being logged.
- `NodeStorage` writes atomically (temp file and rename). OPFS writes use writable swaps, and event-log flushes are serialised per writer.
- The stdio codec revives every bigint field in commands, queries and events. Query results are the exception (`ndjson-codec-missing-result-revival`).
- UI store selectors return stored fields or primitives. Every interval, timeout and listener in the components is cleaned up. Stale query replies are guarded by transport, timeline epoch or call order.
- Amended: the store's `patchedLineages` set is cleared on every run change, rewind and load, restored with the rest of the projection on a failed change, and rebuilt from the lineage tree's direct patch targets (a lineage whose patch list extends its parent's), which matches how `sim/` inherits patches at speciation.
- Amended: all 27 tracked shell scripts (18 in `scripts/`, 9 in `docket/scripts/`) are executable, use `set -euo pipefail`, and propagate failure. `check.sh` stops at the first failed gate, and Vitest has `passWithNoTests: false`.
